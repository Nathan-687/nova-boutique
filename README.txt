# NOVA — Boutique vêtements

## Lancer le site
Ouvre simplement `index.html` dans un navigateur.

## Modifier la boutique
- Nom : `index.html`
- Produits, prix et photos : `script.js`
- Design : `style.css`

## Mettre en ligne gratuitement
Tu peux publier ces fichiers avec GitHub Pages ou un autre hébergeur statique gratuit.

## Paiement
Le bouton Commander est volontairement en mode démonstration. Pour recevoir de vrais paiements, ajoute un moyen de paiement adapté à ton activité et à ton âge/statut juridique.
